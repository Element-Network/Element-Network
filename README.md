## 👋 About Me

I build and maintain **Telegram-based software products**: multi-bot streaming systems, media processing pipelines, and web players.

- 🔭 Building **Element Network**, a web video player on ArtPlayer.js
- ⚡ Multi-bot streaming backends on **FastAPI + Pyrogram + MongoDB**
- 🎨 Media tooling with **PIL + FFmpeg** (banner generators, thumbnails, transcoding)
- 📫 Reach me on Telegram for collabs and projects
